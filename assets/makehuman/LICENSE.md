# MakeHuman assets (CC0 1.0)

`human.bin.gz` is converted (by `tools/convert_makehuman.py`) from the
MakeHuman base mesh (`makehuman/data/3dobjs/base.obj`) and targets
(`makehuman/data/targets`) at https://github.com/makehumancommunity/makehuman.

MakeHuman's assets — the base mesh, proxies, targets and modifiers — were
released under CC0 1.0 Universal (public domain dedication) in September
2020. From MakeHuman's `license.txt`:

> These assets have been released under CC0 1.0 Universal. In summary this
> means that to the fullest extent possible, it is the intention of the
> MakeHuman project that anyone can do whatever they want with it.

Original copyright holders before the CC0 release: Manuel Bastioni (2014),
Data Collection AB, Joel Palmius, Jonas Hauquier (2020).

Only these data files are used. No MakeHuman program code (AGPL) is used;
Clide3D's reader and shape mixing are its own (`src/human.rs`).
